# متجر إمداد لمستلزمات طب الأسنان — Emdad Dental Store 🦷

متجر إلكتروني متكامل لمستلزمات طب الأسنان مصمم باللغة العربية (RTL) بهوية بصرية حديثة (أزرق سماوي، فيروزي، وأبيض)، مستوحى من أفضل تجارب متاجر المستلزمات الطبية. يحتوي على كتالوج كامل، وسلة تسوق تفاعلية، وطلب مباشر عبر واتساب، مع لوحة تحكم كاملة لإدارة المتجر وقاعدة بيانات حقيقية.

---

## ✨ المميزات الرئيسية

- **🎨 هوية بصرية مخصصة:** تصميم عصري متناسق مع شعار "إمداد" باللون الفيروزي والسماوي والأبيض، مع دعم كامل للاتجاه من اليمين لليسار (RTL) وخط Cairo.
- **🎬 أنميشن وتفاعلات سلسة:**
  - سلايدر عروض ترويجية متحرك بنسبة (1:0.4) مع تقليب تلقائي وتوقف عند التمرير.
  - كروت منتجات ترتفع وتكبر عند مرور الفأرة مع تأثير "عرض المنتج".
  - سلة تسوق جانبية منسدلة (Slide-over Cart Drawer).
  - مؤثرات تحميل عصرية (Skeleton Shimmer).
- **📦 كتالوج المنتجات:** 28 منتجاً مخصصاً لطب الأسنان عبر 8 أقسام سريرية بأسعار الليرة السورية (SYP).
- **💬 تكامل واتساب المباشر:** نموذج طلب مخصص لكافة المحافظات السورية الـ 14 يقوم بحفظ الطلب وتوجيه رسالة منسقة إلى رقم الواتساب: `+963 981 276 182`.
- **🔐 لوحة تحكم الإدارة (Admin Dashboard):**
  - مسار محمي بكلمة مرور `/admin`.
  - إضافة وتعديل وحذف المنتجات مع رفع الصور.
  - إدارة الأقسام والبانرات الإعلانية.
  - متابعة الطلبات وتحديث حالاتها.
- **⚡ أداء فائق:** مبني باستخدام Next.js 14 (App Router) مع Tailwind CSS و SQLite عبر Prisma ORM.

---

## 🛠️ متطلبات التشغيل

- [Node.js](https://nodejs.org/) (الإصدار 18 أو أحدث)
- مدير الحزم `npm`

---

## 🚀 طريقة التشغيل السريع

1. **استنساخ المشروع أو الدخول إلى مجلده:**
   ```bash
   cd emdad_store
   ```

2. **تثبيت الحزم والمكتبات:**
   ```bash
   npm install
   ```

3. **تشغيل السيرفر المحلي:**
   ```bash
   npm run dev
   ```

4. **فتح المتجر في المتصفح:**
   - واجهة المتجر: [http://localhost:3000](http://localhost:3000)
   - لوحة تحكم الإدارة: [http://localhost:3000/admin](http://localhost:3000/admin)

## 🏗️ التقنيات المستخدمة

- **Framework:** Next.js 14 (App Router, Server & Client Components)
- **Styling:** Tailwind CSS, RTL Support
- **Typography:** Cairo Variable Font
- **State Management:** Zustand & React Context
- **Database:** SQLite with Prisma ORM
- **Authentication:** Edge Web Crypto & JWT Cookies
- **Icons:** Lucide React
